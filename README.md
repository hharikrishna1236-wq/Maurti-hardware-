# Maruti Hardware
npm install && npm run dev
- Photos: put files in public/images and set `image` in lib/data.ts (e.g. "/images/kitchen.jpg").
- Hafele: set SHOW_HAFELE=true in lib/data.ts only after owner confirms.
- Set NEXT_PUBLIC_SITE_URL to the live domain.
- preview.html: standalone single-file preview of the design (open in any browser).
- Images are built-in illustrations (components/Art.tsx). Replace with real photos via `image` in lib/data.ts.
